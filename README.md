# 🚀 TubeSEO & Tag Genius

An AI-powered YouTube SEO & Metadata Optimization Android App built using **Google AI Studio (Gemini 2.5)** and **Kotlin**.

---

## 🔥 Key Features

* **High CTR Titles:** Generates engaging and click-worthy video titles.
* **Viral Tags & Keywords:** Finds high-ranking search tags and keywords to boost video reach.
* **Trending Hashtags:** Auto-generates top relevant hashtags for YouTube Shorts & Videos.
* **One-Tap Copy:** Easily copy tags, titles, and hashtags to clipboard.

---

## 🛠️ Tech Stack & Powered By

* **Language:** Kotlin / Android Material 3
* **AI Engine:** Google AI Studio (Gemini API)
* **CI/CD Build:** GitHub Actions

---

## 📱 How to Build / Install APK

1. Go to the **Actions** tab in this GitHub Repository.
2. Select the latest successful build under **Build Android APK**.
3. Scroll down to the **Artifacts** section and download `TubeSEO-App-APK`.
4. Extract the ZIP file and install `app-debug.apk` on your Android device!
